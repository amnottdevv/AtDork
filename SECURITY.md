# Security Policy

## About This Project

**AtDork** is an open-source OSINT and automated dorking tool for security researchers, penetration testers, and bug bounty hunters[reference:1]. It is distributed under the **MIT License**.

Because AtDork interacts with search engines, handles proxy credentials, and processes large volumes of external data, we take security issues seriously — but we also ask for **accurate, honest severity assessments**.

## Supported Versions

| Version / Branch | Supported |
| :--- | :--- |
| Latest release | ✅ |
| `master` branch | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

**Do not open a public GitHub issue, discussion, or pull request** for security-related problems. Do not post exploit details or proof-of-concept code publicly before a fix is available.

Send reports privately to:
